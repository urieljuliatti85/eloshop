# Fontes da interface

Servidas pelo próprio app (a CSP só permite `font-src 'self'`), só o
subconjunto latino. Caveat, Fraunces, DM Serif Display e Space Grotesk são as
fontes de título que o artesão pode escolher para a vitrine (`SellerTheme::HEADING_FONTS`).
O navegador só baixa uma fonte quando algum texto da página a usa.
