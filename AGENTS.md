# AGENTS.md

As instruções deste repositório vivem em **[`CLAUDE.md`](CLAUDE.md)**, que vale para
qualquer agente de código — Codex, Claude Code ou outro.

Leia `CLAUDE.md` antes de começar. Ele cobre:

- estado atual do projeto e frentes abertas
- comandos de setup, testes, lint e CI
- arquitetura e as decisões não óbvias a partir da estrutura de arquivos
- quais documentos de `docs/` ler para cada tipo de tarefa
- as regras de domínio, segurança e processo (§1–§70)

E, como manda o próprio `CLAUDE.md`, leia também a seção **"Estado atual"** no fim do
[`ROADMAP.md`](ROADMAP.md) — é a fonte de verdade sobre a fase corrente e a próxima tarefa.

> Este arquivo é só um ponteiro, de propósito. Ele já foi uma cópia integral do
> `CLAUDE.md` e as duas versões divergiram: a cópia daqui descrevia o marketplace como
> não implementado muito depois de ele existir no código. Não reintroduza a duplicação —
